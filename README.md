# CAT BUG — 白背景・1分版

白い画面を黒い6本足の小さな虫が不規則に動き回ります。

## 遊び方
1. START GAMEで1分間のゲームを開始。
2. 画面をタッチすると、その場所から黒い同心円の波が広がります。
3. 波が虫に当たると10点獲得。虫は驚いて素早く逃げます。
4. 1分経過すると終了し、最終得点が表示されます。
5. PLAY AGAINで再挑戦できます。
